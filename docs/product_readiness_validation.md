# 产品就绪度补齐验证记录

日期：2026-11-10。分支：`feat/product-readiness`。本轮保留既有视觉主题，补齐本地数据保护、备份恢复、未提交草稿、失败重试、新手路径和无需 Apple 开发者账号的分发准备。

## 实现范围

- 应用自有 JSON 损坏时保留原文件，报 `storage_corrupt` 并给出文件位置与恢复办法；写入前重新检查磁盘格式版本。修复后可在启动页重试。
- 数据页创建带 SHA-256 清单的私有本地备份，预览并确认恢复。快照绑定预览身份，重新校验后暂存，重启前不替换业务文件；下次启动逐目录换入，恢复记录支持中断重入。
- 恢复前原件和当前表单草稿保留为可检查的恢复历史。未来格式、路径越界、文件类型不匹配、符号链接、篡改、过期预览与并发写入会被拒绝。外部仓库源代码与外部笔记库不包含在快照里，界面和文档会说明。
- 需求输入、访谈回答与课程编辑草稿可跨重启恢复或丢弃；按稳定身份隔离，并校验正式内容基线。已打开页面也不会覆盖后来出现的未来版本草稿。
- 队列区分首次加载、失败和空状态，失败保留旧结果并提供就地重试；数据页提供诊断文本与日志目录，启动错误页保留备份恢复入口，渲染进程退出时提供原生重载提示。
- 新手准备清单分为做项目和学编程，学习不要求已有项目仓库。按有效阻塞检查判断准备度，包含 `custom:grade`；安装和登录指引来自实际配置的角色与 CLI。
- 构建安装包采用 ad-hoc 临时签名，无需 Developer ID；手动构建工作流、SHA-256 脚本和安装/手工更新/验收说明已加入。无远程发布行为。

## 实际窗口与限制

本轮使用独立 `TASKPILOT_DATA_DIR`，不访问用户的真实业务数据，也不启动替代开发服务器。Electron 窗口已成功启动，验证代表页面的浅深色主题与 1100×720、1440×920 renderer 视口；视口通过 CDP 模拟，原生窗口初始大小仍为 1440×920，不把模拟视口当成原生窗口尺寸验收。

实际验证首页项目/学习切换、学习路径不依赖仓库、数据页备份/恢复与故障反馈布局，以及学习需求草稿的真实强退重启恢复：同一 profile 新进程先显示待恢复提示，点击后恢复完整输入和课程模式。未触发付费模型调用或真实用户业务写入。诊断按钮生成了实际诊断文本，验收时将临时页面的剪贴板写入替换为空操作，避免覆盖用户系统剪贴板。

最终打包 App 使用另一个空 profile 启动并显示首页，主进程完成启动；这是本机包内 App 启动验证，不是下载后 Gatekeeper 验收。临时截图、操作结果 JSON 和 profile 位于当次系统临时目录 `taskpilot-readiness-visual-O19H5B`，不进入版本库。

本轮没有运行真实付费模型评测，没有创建远程 Release、推送、注册开发者账号或提交公证。学习 lab 的真实模型通过率、费用与耗时，以及 Apple Silicon/Intel 和不同 macOS 的完整发布矩阵，需要按[分发验收清单](distribution.md)在对应环境记录。临时签名不提供 Developer ID 身份背书，也不等同于公证。
