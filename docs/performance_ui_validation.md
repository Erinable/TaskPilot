## 已实现的行为

- 设置入口延后加载；各设置子页首次访问时才加载和挂载，访问后的页面保持挂载，保留未保存草稿和控件展开状态。
- 校验失败时打开相应子页；即使该页代码尚未加载，也会在挂载后定位错误字段。用户已经离开设置时不抢占焦点。
- 仅次要页面使用的 Element Plus 样式随拥有它们的组件加载，主题覆盖独立于异步加载顺序。
- 全局样式按 shell、执行页面、队列、设置、需求等职责拆分；入口保留原有的导入顺序，继续允许跨组件共享选择器和浮层样式。
- 常用头像渐变、终端差异颜色、彩色底面上的文字等采用语义 token。固定暗色终端和身份配色继续使用其自身的配色语义。辅助中文字号下限调整为 12px。
- 列表的运行状态和在线圆点使用静态提示；当前执行详情和基线测量仍保留进度动效。系统减少动态效果的偏好继续生效。
- 已知数据结构的复制直接脱离 Vue 的可变节点，避免将大篇笔记正文序列化后再解析；覆盖独立嵌套的响应式对象，并保留保存内容与原始草稿之间的隔离。

## 构建体积与图表依赖

用 `npm run build` 生成构建产物，再分别运行 `node scripts/analyze_renderer.ts` 和 `node scripts/analyze_renderer.ts --default-first`。两次命令使用独立 Node 进程，分别把 Dagre 和默认布局作为第一个图表，在相同构建、相同 Mermaid 核心缓存状态下比较冷加载依赖。各自后续阶段共享缓存，代表增量加载，不用于两个布局的冷对照。脚本沿构建产物的静态 import 递归统计启动依赖，单独计算设置入口和个人资料子页新增依赖；不会把 Vite 的懒加载预加载名单误算为启动依赖。报告分别输出到忽略提交的 `.taskpilot/analysis/renderer/renderer-report.json` 和 `.taskpilot/analysis/renderer/renderer-default-first-report.json`。

本轮拆分前后的同环境快照如下（未压缩字节数）：

| 指标 | 拆分前快照 | 优化后 |
| --- | ---: | ---: |
| 启动依赖 CSS 合计 | 302,230 B | 257,580 B |
| 启动依赖 JS 合计 | 1,406,461 B | 1,407,466 B |
| 设置入口首次新增 JS | — | 15,146 B |
| 个人资料子页首次新增 JS | — | 7,072 B |

启动 CSS 减少 44,650 B（约 14.8%）。启动 JS 基本持平（增加 1,005 B），因此没有用单个 chunk 的变化宣称启动 JS 整体减少。快照之间还包含本轮草稿复制及焦点修复，数字不用于隔离每个改动的贡献。

图表依赖测量使用 Node 的模块加载 hook 执行实际构建后的 Mermaid 模块，并以 happy-dom 模拟 SVG 几何方法。项目生成的掌握度图明确指定 Dagre 布局：相较默认流程图首次新增的 2,822,960 B，新增依赖降为 325,577 B，减少约 2.50 MB（88.5%），不再加载约 2.62 MB 的 ELK。这个数字只比较 Mermaid 核心加载完成后的图表依赖，不包括 Mermaid 核心本身，整个应用安装包仍包含 ELK。

后续执行笔记默认流程图和显式 ELK 流程图均成功，默认流程图仍可加载 ELK。思维导图也确实加载 Cytoscape，但模拟环境缺少真实 canvas，未完成其绘制。笔记原有图表能力及默认布局没有被删减。上述探测说明依赖是否加载，不提供真实布局质量、渲染时延或帧率结论。

## 数据复制微基准

环境为 Node 24.12.0 和项目安装的 Vue；输入先通过 `reactive` 包装。每种方法预热 100 次，测量 5 轮取中位数。设置输入每轮复制 5,000 次，笔记每轮 500 次。

| 输入 | JSON 序列化再解析 | `structuredClone(toRaw(root))` |
| --- | ---: | ---: |
| 7 个角色及个人、外观、环境、隔离目录设置 | 93.23 µs/次 | 22.04 µs/次 |
| 7 个检查步骤，各含命令数组及正则解析器 | 176.04 µs/次 | 38.03 µs/次 |
| 正文 110,000 个 UTF-16 字符（约 310 KB UTF-8）的笔记 | 1,407.62 µs/次 | 395.71 µs/次 |

根节点脱离代理后，独立插入的嵌套代理仍然会让 `structuredClone` 抛出 `DataCloneError`，因此没有采用简单替换。实现改为复制每个已知可变节点：笔记显式复制标签、概念和来源，设置显式复制角色、路径数组和检查步骤解析器。笔记按字段复制在同一组测量中约为 1.98 µs/次，因为字符串本身不可变，无需编码再解码。设置在进一步对已知节点使用 `toRaw` 后，10,000 次单轮测量约为 4.00/4.81 µs/次（个人设置/步骤设置）；这组单轮数值只说明方向，不能与上表中位数当作同等精度比较。

这些数据是复制操作的微基准，不能推断为真实应用冷启动、保存全过程或滚动性能提升比例。回归测试另外验证提交数据可被结构化复制、之后修改输入不会改变已提交快照，以及脏状态检测仍然生效。

## 图形环境限制

尝试使用独立临时用户目录运行隐藏的 Electron 窗口，未访问真实用户数据，也没有启动替代开发服务器。环境返回 `sandbox initialization failed: Operation not permitted` 和 GPU 进程初始化失败，进程以 SIGTRAP 退出。

因此本次没有获得可信的真实应用截图、冷启动毫秒数、滚动帧率、GPU 内存或浅色/深色主题的视觉验收结果。这些项目需要在允许启动 Electron 的本机环境复验，尤其关注 12px 角标、窄窗口指标卡、设置页首次打开和日期选择器浮层。
