## 数据兼容与边界

- `mastery.json` 升为 v2，保留掌握度记录、去重信息及旧复习排期。旧版排期只有文件名、没有目录来源，因此按兼容规则仅归属启动时打开的笔记库；未匹配条目继续保留，记录归属后不会被后来打开的其他库领取。
- 新增 `notes_identities.json` v1，位于应用数据目录，不写入用户 Markdown。文件夹身份来自规范化真实路径；应用内重命名保留笔记 UUID。外部重命名或移动整个文件夹按新身份处理，不推测 inode/内容等价。
- 对未来版本的掌握度、笔记身份和课程信任文件保持拒绝写入；测试覆盖启动后磁盘文件被更高版本替换的情况。
